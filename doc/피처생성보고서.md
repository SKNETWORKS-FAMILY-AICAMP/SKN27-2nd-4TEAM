# [Project Report] 다중 모델 기반 이탈 예측 시스템 고도화 전략

## 1. 개요 (Executive Summary)
본 프로젝트는 이커머스 고객의 비정형적 구매 패턴을 분석하여 **이탈(Churn) 위험군을 선제적으로 식별**하기 위해 수행되었습니다. 특히 초기 모델에서 발생한 통계적 왜곡(다중공선성)을 해결하고, **'시간적 맥락'**을 반영, 모델의 판별 성능을 비약적으로 향상시켰습니다.

* **대상 모델:** XGBoost, Random Forest, MLP (Multi-Layer Perceptron) 등 다중 분류 모델군
* **핵심 성과:** **ROC AUC 0.9413** 달성 및 **F1-Score 약 11.28%p** 개선 (0.62 → 0.74)

---

## 2. 전략적 특성 생성 (Feature Engineering)
고객의 단순 상태 정보를 넘어, 행동의 **'변화 추세(Trend)'**를 포착하는 5가지 핵심 지표를 설계했습니다.

| 분류 | 변수명 | 산출 로직 | 비즈니스 가치 (Insight) |
| :--- | :--- | :--- | :--- |
| **활동 급감** | `Dormancy_Shock` | `Recency` / `Avg_Interval` | **핵심 지표.** 개인별 구매 주기 대비 현재 공백기의 심각도를 수치화하여 '이상 징후' 포착. |
| **활동 밀도** | `MonthlyOrderFreq` | `OrderCount` / `Tenure` | 가입 기간 대비 활동량을 정규화하여 장기/단기 고객 간의 활동 스케일 편향 제거. |
| **생애 주기** | `Recency_Tenure` | `Recency` / `Tenure` | 전체 가입 기간 중 휴면이 차지하는 비중 산출. 모든 모델에서 가장 강력한 변별력 제공. |
| **혜택 민감** | `Promo_Sensitivity` | `CouponUsed` / `OrderCount` | 가격 저항력이 낮고 혜택 종료 시 이탈 확률이 높은 '체리피커' 집단 정밀 식별. |
| **정체 로열** | `Stagnant_Loyal` | `Tenure>=30` & `Freq < Avg` | 고가치 장기 고객 중 활동성이 급감한 '방치된 VIP' 그룹을 바이너리화하여 가이드 제공. |

## 3. 통계적 정합성 및 데이터 정제 (Data Sanity Check)
신경망(MLP)의 수치적 불안정성을 해소하고 트리 모델의 과적합을 방지하기 위해 다음의 **3단계 정제**를 수행했습니다.

1.  **VIF 임계값 기반 필터링:** 다중공선성 지수(VIF)가 15를 상회하는 변수(`SatisfactionScore` 등)를 제거하여 모델 가중치 왜곡 방지.
2.  **데이터 누수(Leakage) 차단:** 파생 변수의 재료가 된 원천 데이터(`OrderCount`, `Recency` 등)를 삭제하여 동일 정보의 중복 학습(Double Counting) 방지.
3.  **수치 안정성(Stability) 확보:** 분모 0 에러 방지를 위한 `.clip(lower=0.1)` 보정 처리를 통해 경사 하강 학습의 안정성 극대화.

## 4. 고(高) 상관 피처(0.72) 공존에 대한 기술적 검증

![최종 성능 결과 그래프](/doc/image/output.png)

히트맵 분석 결과 특정 변수 간 **0.72의 높은 상관성**이 관측되었으나, 이를 유지한 전략적 판단 근거는 다음과 같습니다.

* **독립적 설명력 확보:** 두 변수의 공통 분산 외에 존재하는 **약 49%의 고유 정보**가 이탈자(FN)를 가려내는 결정적 단서임을 확인.
* **알고리즘별 수용성:**
    * **Tree 계열:** 정보 이득(Information Gain)이 높은 변수를 선택적으로 취하므로 두 관점을 모두 제공하는 것이 성능 향상에 유리.
    * **MLP 계열:** 타 변수 정제를 통해 **최종 VIF를 13.8 수준**으로 방어하여 수치적 노이즈를 통제 가능 범위 내로 유지.
* **결과 증명:** 변수 유지 시 **ROC AUC 0.9413**으로 최고 성능을 기록하며, 삭제 시보다 정밀도와 재현율의 균형이 월등함을 입증.
